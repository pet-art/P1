# مساعدي الشخصي

مساعد يعمل من الجوال (كتابة أو صوت) ويعتمد على Claude:
- ينفّذ طلبات عملائك التسويقية (محتوى، إعلانات، عروض).
- يبحث على الويب عن عملاء جدد ويحفظهم في قائمة.
- يصوغ رسائل التواصل ويحفظها كمسودات؛ **أنت من يرسلها** بعد المراجعة.
- يتذكر العملاء والمهام في `data/db.json`.

## التشغيل
```
cp .env.example .env     # ثم ضع ANTHROPIC_API_KEY و ACCESS_PASSWORD
npm install
npm start                # http://localhost:8080
```

## على الجوال
انشر المجلد على أي استضافة Node (Render, Railway, Fly.io…) مع متغيرات البيئة نفسها واستعمل HTTPS (مطلوب للميكروفون)،
ثم افتح الرابط في Chrome/Safari واختر "إضافة إلى الشاشة الرئيسية".
الإدخال الصوتي يستخدم ميزة المتصفح (Chrome على أندرويد يعمل بشكل أفضل).

## ملاحظات
- التخزين ملف JSON بسيط ومناسب لمستخدم واحد؛ على استضافة بلا قرص دائم ستضيع البيانات عند إعادة التشغيل، فاربط مجلد `data/` بقرص دائم.
- حماية الدخول بكلمة سر واحدة؛ لا تشارك الرابط علناً.
